### 📄 Campo 1: Resumen Ejecutivo y Descripción del Proyecto (Executive Summary)
> **Español:**  
> TRUSTIA es una plataforma de software de autonomía militar de Grado 2.0 y doble uso (*dual-use*), diseñada específicamente para vehículos terrestres no tripulados (UGV/İKA) que operan en entornos tácticos y hostiles sin señal GNSS/GPS (*GPS-denied environments*). Desarrollado bajo una arquitectura modular determinista en Python (15.401 líneas de código de producción), TRUSTIA integra algoritmos propietarios de SLAM 3D de grafo de poses (*3D Pose Graph SLAM*), odometría visual y un motor de fusión sensorial multimodal en tiempo real (inducción metálica + anomalía térmica + radar GPR). El sistema detecta y neutraliza automáticamente amenazas asimétricas (artefactos explosivos improvisados - IED, minas terrestres y riesgos radiológicos/químicos - CBRN), creando zonas dinámicas de cuarentena de seguridad de 30 metros. TRUSTIA cumple estrictamente con los estándares internacionales SAE JAUS (AS6009/AS6091), STANAG 4586, ROS 2 y CAN FD, y está 100% validado mediante una batería de 1.276 pruebas unitarias automatizadas con cero fallos.
